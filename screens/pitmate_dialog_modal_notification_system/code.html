Design System Implementation Standard

1. FOCUS TRAPPING & ACCESSIBILITY

All dialogs must trap keyboard focus, bind Esc to dismiss, and set aria-modal="true" on mounting.

2. DESTRUCTIVE ACTIONS DOUBLE-GATE

Actions involving records or telemetry deletions require an explicit confirmation button and cannot rely on simple prompt defaults.

3. AUTO-DISMISS TOAST TIMINGS

Success toasts auto-dismiss after 4000ms. Critical error and inventory reservation alerts persist until manually acknowledged.
